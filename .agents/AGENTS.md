# Project Preferences & Guidelines

- **Deployment Rules**: Only deploy by pushing to GitHub (`git push`) and using Expo OTA Update (`npx eas-cli update`) when there are modifications inside the `mobile/` directory. Do not run manual Vercel CLI deployments (`npx vercel`).
- **Language Rules for Deployment & Updates**: Always write git commit messages and Expo OTA update messages (`--message` / `-m`) in Indonesian.


- Jika proses penulisan kode atau pembuatan fitur telah selesai, SEGERA lakukan commit/push ke GitHub dan jalankan update OTA secara otomatis tanpa perlu meminta izin/bertanya terlebih dahulu kepada pengguna.
